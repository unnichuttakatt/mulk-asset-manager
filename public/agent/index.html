Mulk Agent

The company program for a Windows laptop or desktop. It is a separate install from the asset register. Intune is not required.

Mulk Agent stays quiet. Its icon is in the taskbar corner, behind the up arrow at the bottom right. The person clicks that icon when they need support. The window does not open by itself, and PowerShell does not stay on the screen. They can ask for admin rights from that window. IT approves or denies that request in Control. A short approval adds that Windows account to Administrators and removes it when the time ends. USB storage follows the rule set.

Every few minutes the program sends the installed software list: program name, version, and publisher from the Windows uninstall list. The first list is the baseline. A program that appears later is an alert on the Alerts page. It also sends health: BitLocker, Microsoft Defender, the firewall, free disk space, whether a restart is waiting, the manufacturer, model, serial, memory, the names of local administrators, and the names of startup programs. It does not read the files those programs open.

It also sends the public IP address and the city and country that IP belongs to. A country other than the UAE is an alert. It does not use GPS. USB devices already connected at the first check are the baseline. A USB device plugged in after that is an alert, by device name only. Files on the drive are not listed.

While someone is at the computer, it counts active minutes and which app is in front. Google, Bing, DuckDuckGo, Yahoo, and YouTube searches made after this starts are listed under Usage. Searches already in the browser are not imported. Page contents, documents, the screen, and the keyboard are not collected.

Office hours are 8:00 AM to 6:00 PM. If the computer is still on after 6:00 PM, IT gets an alert. The next time the person uses it, they see an office-standard reminder to shut it down when they leave the office. The reminder does not include the screen or anything typed.

The checks are light. A short check runs about every 5 minutes. The software list, health, USB names, and new searches are read about every 2 hours. It does not scan files.

From Control, IT can set the built-in Administrator password once. The computer applies it and the password is then deleted. It is not written to the agent log, and the account is not enabled by that change. Software is installed only from Bulk install. That asks for a separate install password, then the same HTTPS installer is queued for the ticked computers. Each computer downloads it, runs it, and deletes the file. This is not a remote command prompt, and it does not lock sign-in.

The person can choose Request remote help in the Mulk Agent window. IT sees that on the dashboard and can ask to connect. Quick Assist opens only after the person chooses Allow. Mulk stores only whether they allowed it. It does not save the screen, and it does not record the keyboard. This is not a hidden connection.

Install on one computer

  1. Download Mulk Agent setup. On the computer, run MulkAgentSetup.exe. Windows asks for administrator approval. No code is required.
  2. Confirm the Windows account of the person who uses that computer, then choose Install.
  3. In Control, the computer appears under Installed systems waiting for an asset, with its system name and Windows accounts. Choose the asset and assign it.
  4. The window does not open. Click the up arrow at the bottom right of the taskbar and choose Mulk Agent when support is needed. It waits, and does not report, until an admin assigns it.

Update an existing install

Once this version is on a computer, it checks the company site about every 30 minutes. When a newer Mulk Agent is published, the computer replaces its own copy. The scheduled checks use the new copy on the next run. Close any Mulk Agent or PowerShell window that is already open. The icon then stays behind the up arrow. Computers that still have an older copy need this command once in an Administrator PowerShell. It does not need a new code.

powershell -NoProfile -ExecutionPolicy Bypass -Command "Invoke-WebRequest https://mulk-asset-manager.vercel.app/agent/MulkAgent.ps1 -OutFile C:\ProgramData\MulkAgent\MulkAgent.ps1; powershell -NoProfile -ExecutionPolicy Bypass -File C:\ProgramData\MulkAgent\MulkAgent.ps1 -Enforce"

Remove it

In an Administrator PowerShell:

schtasks /Delete /TN "Mulk Agent Enforce" /F
schtasks /Delete /TN "Mulk Agent Watch" /F
schtasks /Delete /TN "Mulk Agent Sample" /F
schtasks /Delete /TN "Mulk Agent Tray" /F
Remove-Item "$env:ProgramData\Microsoft\Windows\Start Menu\Programs\StartUp\Mulk Agent.lnk" -Force
Remove-Item "$env:ProgramData\Microsoft\Windows\Start Menu\Programs\Mulk Agent.lnk" -Force
Remove-Item C:\ProgramData\MulkAgent -Recurse -Force

Mac computers are not covered by this installer.
